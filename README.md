# Memory-App

## Projekt starten

Im Terminal im Projektordner:

```bash
npm install
npm run dev
```

Danach die im Terminal angezeigte Adresse im Browser öffnen.
Mit `npm run build` wird eine fertige Version im Ordner `dist` erstellt.

## Wo finde ich was?

- `index.html`: die kurze HTML-Einstiegsseite.
- `src/main.ts`: Einstieg, Einstellungen und Reaktionen auf Klicks.
- `src/game.ts`: Karten mischen, Spielzüge und Punkte.
- `src/screens.ts`: HTML für Start, Einstellungen, Spiel und Ergebnis.
- `src/types.ts`: gemeinsame TypeScript-Typen und Einstellungen.
- `src/styles/style.scss`: bindet die einzelnen SCSS-Dateien ein.
- `src/styles/`: Styles für Start, Einstellungen, Spiel, Ergebnis und kleine Bildschirme.
- `public/cards/`: Kartenbilder nach Thema sortiert.
- `public/theme-previews/`: Vorschaubilder für die Einstellungen.
